# Soul on Tenth concept preview

A concept website for Soul on Tenth (118 10th St, Brandon, MB), made by Tyler Wedderburn as part of a proposal. **It is not the official Soul on Tenth website.** Book buttons open the matching service on Soul's Square Appointments page, and shop links go to its Square Online store.

`data/services.json` and `data/staff.json` were taken from Soul's public Square booking page on November 17, 2026. Each artist's specialty is worked out from the services they offer.

Edit `build.py` and run `python build.py` to regenerate the HTML.
